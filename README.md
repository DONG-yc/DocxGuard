# DocxGuard

DocxGuard 是一个用于定点更新 Word 文档的工具。它适合需要反复更新同一份模板的场景，例如项目周报、实验报告和统计报表。你可以指定要改的文字、表格或图片，先预览改动，再生成新的 DOCX 和修改报告。原始模板始终保留。

## 可以用它做什么

- **更新文字**：按原文定位并替换项目名称、日期或段落中的短语，支持一次提交多项修改。即使 Word 把一句话拆成多个格式片段，也能定位其中的文字。
- **更新表格和配图**：在已有表格末尾追加数据行，沿用模板行的格式，并把指定图片替换为准备好的新版 PNG。
- **让 Agent 编辑本地文档**：通过 MCP 把检查、定位、预演和发布能力提供给 AI Agent。目标有歧义时，Agent 可以根据段落、表头或图题向用户确认。

## 怎样使用

开发者可以直接通过命令行调用 DocxGuard，也可以将它作为本地 MCP 工具接入 Agent。两种方式遵循同一套工作流程：

1. **检查模板**，找到要更新的内容。
2. **预演修改**，核对目标位置与替换内容。
3. **确认并发布**，在新目录中取得输出文档和修改报告。

## 适用范围

DocxGuard 面向已有 DOCX 模板的局部更新。表格追加目前支持正文中的普通顶层表格；图片替换支持独占引用、像素尺寸相同的 PNG。涉及文字换行和跨页时，可在 Word 中核对最终排版。
